# Бильярд

Ботқа қарсы немесе досыңмен бір компьютерде ойнауға болатын бильярд. Режим таңдау
мәзірінде негізгі төрт ойын қалдырылды: еркін пирамида, пул-8, снукер және үш
бортты карамболь. Пирамидада ақ шарлар үлкейтіліп, лузалар тарылған. Доптардың
жылдамдығы аздап төмендетілген. Қазақша/орысша/ағылшынша мәзір мен үш қиындықтағы бот
бар. Ойын іске қосылғанда жай фондық әуен қайталанып ойнайды.

Баптаулар үш бөлімге бөлінген: дыбыс, экран, тіл және бот. Музыка мен ойын дыбысының
деңгейін бөлек реттеуге болады. Экран ажыратымдылығы: 640×480 VGA, 800×600 SVGA,
1024×768 XGA, 1280×720 HD, 1366×768 HD, 1600×900 HD+ және 1920×1080 Full HD.
Сондай-ақ FPS шегі мен графика сапасы (төмен, орташа, жоғары) реттеледі. Баптаулар
автоматты түрде сақталады.

## Ubuntu-да іске қосу

```bash
sudo apt update
sudo apt install -y build-essential cmake git libopenal-dev \
  libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev \
  libgl1-mesa-dev
cd Billiards
cmake -S . -B build
cmake --build build -j
./build/bin/billiards
```

Алғаш құрастырғанда GLFW 3.4 GitHub-тан жүктеледі. GLAD кітапханасы репозиторийдегі
`external/glad` бумасынан алынады. Ойын баптауларын `billiards_save.txt` файлына сақтайды.

## Ойнау

- Мәзірден ботпен немесе досыңмен ойнауды, кейін ойын режимін таңда.
- Алдымен үстелдегі нүктені басып соққы бағытын таңда. Содан кейін төмендегі күш жолағын басып, қажетті күшті қой да, «Соғу» батырмасын бас. «Бас тарту» таңдалған соққыны өшіреді.
- Пул-8-де 1–6 пернелерімен 8-доп түсетін лузаны алдын ала таңда.
- Динамикалық пирамидада фолдан кейін битті үстелдің кез келген жеріне оң жақ түймемен қой.
- Барлық доп тоқтағанша кезек ауыспайды. Доп салсаң, қайта соғасың.
- Ақ допты қалтаға түсірсең, фол болып кезек қарсыласқа өтеді.
- Пирамидада бірінші 8 шарды салған, классикалық пирамидада 71 ұпай жинаған ойыншы жеңеді.
- Пул-8-де топтағы шарларды тазалап, алдын ала таңдалған лузадан 8-допты түсір; пул-9-да ретпен тұрған нысаналы шарға соқ.
- Стрейт пул 100 ұпайға дейін ойналады.
- Снукерде шар ұпайлары, карамболда борт саны есептеледі.
- `Esc`: ойын, баптаулар немесе режим таңдау экранынан басты мәзірге қайту.
