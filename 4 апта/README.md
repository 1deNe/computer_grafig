# 4-апта: Uniform, уақыт, delta time

`4-week.cpp` 3-аптаның коды негізінде жасалды. Бір төбесі жоғары тұрған
градиентті үшбұрыш сақталған. Шеңбер бойымен қозғалыс, пульсация және
жылдамдықты басқару қосылды. Орбитаның радиусы 0.4; геометрия экранға сыйып
тұру үшін сәл кішірейтілді. Фон, FPS және алдыңғы пернелер сақталған.

## Іске қосу (Архив папкасынан)

```bash
cmake -S . -B build-week04
cmake --build build-week04 --target week04 -j
./build-week04/bin/week04
```

## Басқару

- W / S: жылдамдықты арттыру / азайту (0.1–10 радиан/секунд).
- R: жылдамдықты, орбитадағы бұрышты және режимдерді бастапқы күйге қайтару.
- F: dt жоқ экспериментке ауысу; қайта басқанда қалыпты dt режимі қайтады.
- 1: кері түс; 2: бірдей түс; 4: шахмат өрнегі.
- 5: бірдей түс режиміндегі түсті өзгерту; 6: контур режимі.
- 7: алдыңғы аптаның шейдер қатесін тексеру.
- Space: ақ фон; Esc: шығу.

## 1-тапсырма: dt жоқ эксперимент

Бастапқы режимде `angle += speed * dt` орындалады; VSync өшірулі.
F басқанда `angle += 0.02f` орындалады. Екі компьютерде F режимін қосып,
консольдегі FPS пен айналу жылдамдығын салыстырыңыз. Тапсыру алдында F
режимін өшіріңіз немесе R басыңыз; қайта іске қосқанда dt автоматты қосылады.

Нақты екі компьютердегі тәжірибе әлі жасалған жоқ. Өз бақылауыңызды төменге
жазыңыз:

Менің компьютерімде: ___ FPS, қозғалыс ___. Көршімнің компьютерінде: ___ FPS,
қозғалыс ___. dt жоқ кезде әр кадрда бірдей 0.02 радиан қосылады, сондықтан
FPS жоғары болған сайын секундына көбірек бұрыш қосылып, қозғалыс жылдамдайды.

## Қорғауға түсіндірме

`speed = 1.5f` — кадрға емес, секундына 1.5 радиан. `dt` — соңғы кадрдан
өткен уақыт (секунд). Мысалы, 60 FPS-та кадр сайын шамамен 0.025 радиан,
120 FPS-та 0.0125 радиан қосылады: екі жағдайда да секундына 1.5 радиан.
W/S үшін де dt керек: жылдамдықтың өзгеруі секундына 2 радиан/секунд болады.

`uOffset` қозғалысты, `uScale` өлшемді басқарады. Өлшем
`0.75 + 0.25 * sin(now * 2)` арқылы 0.5–1.0 аралығында өзгереді.
Uniform орындары цикл алдында бір рет табылады; мәндері `glUseProgram`
шақырылғаннан кейін орнатылады. `lastFrame` ағымдағы уақыттан басталады.

Осы ортада компилятор қолжетімсіз, WSL бұғатталған. Құрастыру, терезедегі
қозғалысты және екі компьютердегі тәжірибені тексеру орындалған жоқ.
