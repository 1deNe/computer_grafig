# 3-апта

3-week.cpp пайдаланушы берген кодтан өзгертілді. Бір жоғары қарап тұрған үшбұрыш, фон, FPS, Space және 6 контур режимі сақталған.

```bash
cmake -S . -B build-week03
cmake --build build-week03 --target week03 -j
./build-week03/bin/week03
```

1 — кері түс; 2 — бірдей түс / RGB градиенті; 4 — шахмат өрнегі.
5 — бірдей түс режиміндегі қызыл/көгілдір түс; 6 — контур; Space — ақ фон; Esc — шығу.
7 — әдейі vec5 қатесі. Нақты хабарлама консольге және ағымдағы папкадағы README-week03-error.md файлына жазылады. Негізгі шейдер дұрыс.

Растеризатор vertex шейдерден шыққан түстерді интерполяциялайды. Fragment шейдер сол мәндерді алады. Төбелердің түсі бірдей болса, градиент жоғалады.
gl_Position clip кеңістігіндегі орынды анықтайды. Оның есептеуіне қатыспайтын айнымалыны өзгерту орынды өзгертпейді.
makeShader компиляцияны glGetShaderiv, линковканы glGetProgramiv арқылы тексереді. Қате режиміндегі vec5 шейдердің 4-жолында орналасқан.

Осы ортада компилятор табылмады, WSL бұғатталған. Құрастыру мен графикалық тексеру орындалған жоқ; нақты драйвер хабарламасын алу үшін 7 пернесін басыңыз.
