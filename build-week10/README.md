# 10-апта: тінтуір және еркін камера

Жоба 9-аптадағы main.cpp, CMake, GLAD және тесттер көшірмесінің негізінде жасалды.
9-апта файлы мен осы папкадағы бастапқы PDF құжаттары өзгертілмеді.

## Іске қосу

Алдыңғы апталардағыдай C++17, CMake, GLFW, GLAD және GLM қолданылады.
Негізгі код main.cpp ішінде, құрастыру CMakeLists.txt арқылы орындалады.
Осы папканы өзіңіз қолданатын CMake қолдайтын редакторда ашып,
week10 нысанасын құрастырып іске қосыңыз.

Терминалда осы папкадан:

```text
cmake -S . -B build-local
cmake --build build-local --config Debug --target week10
```

Windows-та құрастырылған бағдарламаны run-week10.cmd арқылы ашуға болады.
Құрастыру үшін CMake және C++ компиляторы қажет.

## Басқару

Әдепкі үйлесімді режим: тінтуірдің ОҢ батырмасын басып ұстап, жылжытыңыз.
Курсор шетке жетсе, батырманы жіберіп, курсорды ортаға әкеліп қайта ұстаңыз.
Бұл режим курсорды жасырмайды және автоматты түрде ортаға көшірмейді.
F2 тапсырмадағы GLFW_CURSOR_DISABLED FPS режиміне және кері ауыстырады;
сол режимде қолжетімді болса GLFW_RAW_MOUSE_MOTION қолданылады.
Фокуссыз терезедегі тінтуір оқиғалары камераға әсер етпейді.

Қозғалыс түзетуі: жылдамдық 1.5 бірлік/секунд, Shift кезінде 3.0.
Диагональ қозғалыс жылдамдықты арттырмайды. Кадр уақыты 0.05 секундпен
шектелді; фокус жоғалғанда қозғалыс тоқтайды, қайтқанда алғашқы тінтуір
координаты қайта алынады. Осы соңғы түзетуден кейін құрастыру мен тесттер
қайта орындалған жоқ.

| Енгізу | Әрекет |
| --- | --- |
| Оң батырманы ұстап тінтуірді жылжыту | yaw/pitch арқылы камераны бұру |
| F2 | Үйлесімді режим / курсор ұсталатын FPS режимі |
| Дөңгелек | FOV зумы, 1–90 градус |
| W/S, A/D | Камера бағытына қарай алға/артқа, солға/оңға |
| Space / сол Ctrl | Жоғары / төмен |
| Shift | Екі есе жылдам қозғалу |
| I | Invert Y қосу/өшіру |
| P | camPos, camFront, yaw, pitch, fov және бағыт ұзындығы |
| R | Камера орнын, бұрыштарын, FOV және pitch шектеуін қалпына келтіру |
| 1 / 2 / 3 | sensitivity: 0.03 / 0.1 / 0.5 |
| B | Тәжірибе үшін pitch шектеуін өшіру/қосу |
| 5 / 0 | 5 / 10 куб |
| Tab | Қаңқа режимі |
| O | 9-аптадан қалған координат басына қарау тәжірибесі |
| Esc | Шығу |

Негізгі тапсырмаларды қалыпты еркін камера режимінде орындаңыз; O режимінен R арқылы қайтуға болады.
9-аптадағы Shift төмен жүру қызметі Ctrl-ға көшірілді: Shift енді тапсырма бойынша жүгіреді.

## Міндетті тапсырмалар және қорғау

### 1. Pitch шектеуі

Қалыпты режимде pitch ±89° аралығында. B шектеуді уақытша өшіреді,
тінтуір қозғалғанда pitch консольге шығады. Тәжірибеден кейін R басыңыз.
`--preset broken` шектеусіз pitch=90° көрінісін қайталайды.

Математикалық түрде cos(90°)=0, camFront=(0,1,0), ал camUp=(0,1,0).
Олардың cross көбейтіндісі нөл. lookAt ішіндегі normalize нөлдік векторды
нормалағанда нөлге бөлу нәтижесінде NaN пайда болуы мүмкін.

Маңызды сандық ерекшелік: float форматында cos(radians(90)) дәл нөл болмауы
мүмкін. Сондықтан 90° кезінде міндетті түрде NaN шығады деп айту дұрыс емес.
Бір түсті кадр кубтардың камераның көру аймағынан шығып кетуінен де болады.
Тест шектеусіз 90° үшін cross ұзындығын және view матрицасының ақырлы болуын
шығарады; дәл параллель (0,1,0) бағыты үшін бөлек сингулярлықты тексереді.
04-broken.png — шектеусіз 90° кезіндегі нақты кадр, NaN-ның жеке дәлелі емес.

### 2. Sensitivity

Әдепкі sensitivity=0.03 таңдалды: пайдаланушыға 0.1 тым жылдам болғандықтан азайтылды.
360° бұрылу үшін тиісінше 12000, 3600 және 720 тінтуір координат бірлігі қажет.
1/2/3 арқылы мәндерді ауыстырып, өз тінтуіріңізбен толық айналып салыстырыңыз.
Тінтуірді неше рет көтеру керегі DPI мен үстелдегі бос орынға тәуелді;
пайдаланушының қолмен сынауы орындалды деп есептелмейді.

Дәрістегі const мәннің өзгермейтінін көрсетеді. Бұл жобада мән пернемен
өзгеретіндіктен жаһандық float қолданылған. Тінтуір ығысуын dt-ге көбейтпейміз:
ол жылдамдық емес, орын ауыстыру. WASD жылдамдығы dt-ге көбейтіледі.

### 3. Invert Y

I басылғанда yoffset таңбасы ауысады. GLFW key callback ішінде тек GLFW_PRESS
қабылданады, GLFW_REPEAT еленбейді. Бұл алдыңғы перне күйін сақтаудың баламасы:
ұстап тұрғанда қайта-қайта ауыспайды. WASD үздіксіз қозғалыс болғандықтан
әр кадрдағы басулы күйді оқиды.

### 4. Камера күйі

P толық күйді бір рет шығарады. camFront нормаланады. Float дөңгелектеуінен
ұзындығы дәл 1 емес, оған өте жақын болуы мүмкін. sin/cos формуласы теорияда
бірлік вектор береді, сондықтан normalize алып тасталса да ұзындығы 1-ге жуық;
normalize сандық ауытқуды азайтады.

### 5. FOV 90°

Дөңгелекті артқа айналдырғанда FOV 90°-қа дейін өседі. Кең бұрышта көбірек
сахна сыяды, орталықтағы зат кішірейеді, шеттегі заттар созылғандай көрінеді.
Бұл перспективалық проекцияның қалыпты қасиеті. Проекция масштабында
1/tan(FOV/2) қолданылады; FOV өскенде бұл коэффициент азаяды.

## Қосымша тапсырмалар

Төртеуі де қосылған: Shift жүгіру, терезе атауындағы yaw/pitch/fov,
R арқылы бастапқы күй және yaw-ды fmod арқылы (-360,360) аралығында сақтау.
firstMouse алғашқы қозғалыста камераның секіруін болдырмайды.

## Тексеру және скриншоттар

```bash
ctest --test-dir build-local -C Debug --output-on-failure
./build/bin/camera_tests
```

Тесттер 9-аптадағы қозғалыстарға қоса алғашқы тінтуір оқиғасын, бағыттарды,
invert Y және перне қайталауын, pitch/FOV шектерін, yaw, reset және
параллель бағыттың сингулярлығын тексереді.

Скриншоттар нақты OpenGL кадрларынан алынады:

- screenshots/01-default.png — бастапқы көрініс.
- screenshots/02-looking-up.png — төменірек орналасқан камераның жоғары қарауы.
- screenshots/03-zoomed.png — FOV=25° жақындату.
- screenshots/04-broken.png — pitch=90°, шектеу өшірулі.

Қайта алу үлгісі: `./build/bin/week10 --frames 3 --preset up --capture up.ppm`.
Пресеттер: default, up, zoom, broken. Capture режимінде тінтуірді ұстамаймыз,
сондықтан скриншотқа арналған қалыпқа кездейсоқ курсор қозғалысы әсер етпейді.

Осы компьютердегі тексеру нәтижесі: Ubuntu / GCC 15.2 арқылы құрастыру сәтті,
CTest 1/1 өтті. Төрт пресет OpenGL 4.5 / Mesa 26.0.8 арқылы қатесіз орындалды;
PNG кадрлары көзбен тексерілді. Шектеусіз pitch=90° кезінде cross ұзындығы
4.37114e-08, view матрицасы ақырлы болды. Дәл параллель бағыттағы жеке тест
сингулярлықты растады. Пернетақта/тінтуір callback логикасы автоматты тексерілді;
адамның тінтуірмен ыңғайлылық сынағы жүргізілген жоқ.
