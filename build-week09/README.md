# 9-апта: камера, LookAt, пернетақтамен жылжу

Негізгі код — `main.cpp`. Алдыңғы `computer_grafig/6-week.cpp` және
`Архив` жобаларындағы C++17, GLFW, GLAD, GLM, шейдерлерді тексеру,
VAO/VBO/EBO және FPS құрылымы қолданылды. Бұл папкаларда 7–8-аптаның
кодтары болмағандықтан, 3D куб геометриясы, model/view/projection және
depth buffer осы жобаға қосылды. Кубтар қозғалмайды, тек камера жылжиды.

Тапсырмалар PDF-інде бес куб (z = 0…−4), ал дәрісте он куб (z = 0…−15)
берілген. Сондықтан бастапқы режимде бес куб көрсетіледі; `0` пернесі
он кубты, `5` пернесі бес кубты қосады. Сыртқы сурет/текстура қажет емес.

## Іске қосу

Ubuntu/WSL терминалында репозиторийдің түбірінен:

```bash
cmake -S build-week09 -B build-week09/build
cmake --build build-week09/build --config Debug
./build-week09/build/bin/week09
```

Графикалық терезе үшін WSLg қажет. Осы компьютерде Ubuntu, CMake,
GCC және OpenGL кітапханалары бар.

Немесе Ubuntu терминалында `build-week09` папкасына кіріп:

```bash
cmake -S . -B build
cmake --build build -j 4
./build/bin/week09
```

GLFW/GLM үшін CMake алдымен алдыңғы жобалардағы жергілікті бастапқы
кодтарды іздейді. Олар жоқ болса, GLFW 3.4 және GLM 1.0.1 жүктеледі.
GLAD бастапқы коды осы папкада бар. Жобаны басқа компьютерге көшіргенде
генерацияланған `build/` папкасын көшірмей, жаңадан құрастыру керек.

## Басқару

| Перне | Әрекет |
| --- | --- |
| W / S | Алға / артқа |
| A / D | Камераның сол / оң жағына |
| Space / Left Shift | Әлемнің Y осі бойымен жоғары / төмен |
| Left Control | Басулы кезде екі есе жылдамдық |
| O | LookAt: еркін камера / координат басына қарау тәжірибесі |
| R | Бастапқы камера және дұрыс LookAt режимі |
| P | Камера координатын консольге бір рет шығару |
| 5 / 0 | 5 / 10 куб |
| Tab | Қаңқа / тұтас беттер |
| Esc | Шығу |

Бастапқы камера: `camPos=(0,0,3)`, `camFront=(0,0,-1)`, `camUp=(0,1,0)`.
Жылдамдық — 2.5 бірлік/секунд, Ctrl кезінде 5.0 бірлік/секунд.
`camPos` ұзындығы 20-дан аспайды. Соқтығысу физикасы жоқ: кубтың ішіне
кіруге болады, жақын бет near=0.1 жазықтығында қиылады.

## Тапсырмалар және қорғауға жауаптар

### 1. LookAt-тың екі нұсқасы

Қалыпты режим:

```cpp
glm::lookAt(camPos, camPos + camFront, camUp);
```

Мақсат камерамен бірге жылжиды. Қарау бағыты өзгермейді. Бастапқы
бағытта A камераны әлемнің −X жағына апарады:
`cross((0,0,-1),(0,1,0))=(1,0,0)`, A осы оң векторды азайтады.

Тәжірибе: `R`, кейін `A` басып көріңіз. `R`, `O`, қайтадан `A`
бассаңыз, камера орнын ауыстырғанда координат басына қарай бұрылады.
`O` қайта басқанда дұрыс `camPos + camFront` режимі қосылады.

Тұрақты мақсат модельді немесе нысанды сыртынан қарауға ыңғайлы.
Нақтылау: тек lookAt мақсат нүктесін ауыстыру камера орнын өздігінен
шеңбермен жүргізбейді. Бұл кодта A/D қозғалысы сол тұрақты `camFront`
негізінде түзу бойымен жүреді; өзгеретіні — көздеу бағыты. Нағыз орбита
үшін камераның позициясын да нысанның айналасындағы бұрыштан есептеу керек.
Нөлдік және Y осіне параллель бағыттар тәжірибе режимінде қорғалған.

### 2. Жоғары-төмен қозғалыс

Space және Left Shift үшін әлемнің `(0,1,0)` осі таңдалды. Бұл ойын
кейіпкері үшін ыңғайлы: жоғары қозғалыс әлемнің жоғарысын сақтайды.
Ұшақта ұшақтың өзіне қатысты, еңкеюімен бірге өзгеретін up векторы
қолайлы. Қазір `camUp=(0,1,0)` болғандықтан, екі тәсілдің нәтижесі бірдей.

### 3. Жүгіру режимі

```cpp
float speed = 2.5f * dt;
if (sprint) speed *= 2.0f;
```

Ctrl басулы кезде жылдамдық екі еселенеді. Көбейткішті dt-ден бұрын
қолдану математикалық нәтижені өзгертпейді: `(2.5 * dt) * 2` және
`(2.5 * 2) * dt` бірдей, тек float дөңгелектеуінде өте аз айырма болуы мүмкін.
dt секундпен есептелетіндіктен қозғалыс FPS-ке тәуелсіз.

### Негізгі кодтың байланысы

`dt` есептелген соң `processInput(window, dt)` шақырылады.
A/D бағыты — `normalize(cross(camFront, camUp))`.
View әр кадрда қайта жасалады. Model әр куб үшін тұрақты орыннан жасалады.
Шейдердегі рет: `projection * view * model * vec4(aPos, 1.0)`.
Терезе өзгергенде aspect ratio жаңарады, терезе кішірейтілгенде нөлге
бөлу болмайды. Тінтуірмен бұрылу келесі аптаның тақырыбына қалдырылған.

## Тексеру

Камераның сандық тексерістері:

```bash
ctest --test-dir build --output-on-failure
```

Тесттер нақты `main.cpp` функцияларымен 30/144 FPS кезіндегі бір секундтық
қозғалысты, WASD, Space/Shift, Ctrl, нөлдік dt, қарама-қарсы пернелерді,
бұрылған камераның нормаланған strafe бағытын, радиус шегін, LookAt,
тәжірибе режимінің шеткі жағдайларын, R және 5/10 куб режимдерін тексереді.

OpenGL іске қосуын шектеулі кадрмен тексеріп, PPM скриншот алуға болады:

```bash
./build/bin/week09 --frames 30 --capture preview.ppm
./build/bin/week09 --frames 30 --ten-cubes --capture preview-ten.ppm
```

Осы ортадағы нәтиже: Ubuntu / GCC 15.2.0 арқылы құрастыру сәтті;
CTest — 1/1 өтті. Екі сахна да OpenGL 4.5 Core / Mesa 26.0.8 арқылы
30 кадр жұмыс істеді; шейдер және OpenGL қатесі тіркелмеді.
`preview.png` және `preview-ten.png` скриншоттары визуалды тексерілді.
Қалыпты пернетақта енгізуін қолмен толық тексеру жүргізілген жоқ;
қозғалыс пен ауыстырғыштар автоматты тестте тексерілді.

Репозиторийге бастапқы код, CMake, тесттер, нұсқаулық және скриншоттар
қосылады. Генерацияланған `build/` папкасы Git-ке қосылмайды.
